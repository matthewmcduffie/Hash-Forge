Plain-English Usage Notes

Use generated secrets for API keys, app secrets, JWT secrets, encryption keys, admin passwords, service credentials, and test tokens.

Use hashes for checksums, duplicate detection, file integrity, and proving that text or files match exactly.

Do not store user passwords as plain SHA hashes. Real password storage should use Argon2id, bcrypt, or PBKDF2 with salts and sane work factors. Browser SHA tools are good for fingerprints, not password databases.

Keep private secrets out of screenshots, chat windows, logs, Git commits, and shared drives. The old ways still win here: lock the drawer, label the keys, and do not hand copies to strangers.
